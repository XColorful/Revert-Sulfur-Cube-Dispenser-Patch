# Revert Sulfur Cube Dispenser Patch

With the introduction of the Cold Sulfur Cube archetype in 26.4 snapshots, this mod brings the related mechanics back to Minecraft 26.2 and 26.3.

This mod reverts [MC-307929](https://mojira.dev/MC-307929), so dispensers can equip armor on sulfur cubes again.

Note:
- This mod does not add any new archetypes to Sulfur Cubes. It only removes the restriction on which equipment types dispensers can equip.
